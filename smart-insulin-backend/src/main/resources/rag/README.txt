Place the following PDF files in this directory before building the application:

1. ada_standards_2025.pdf
   Source: ADA Standards of Care in Diabetes – 2025
   URL: https://doi.org/10.2337/dc25-S001

2. moz_ukraine_t1dm_protocol.pdf
   Source: Уніфікований клінічний протокол МОЗ України
           "Цукровий діабет І типу у дорослих"

Files in this directory are automatically ingested into the pgvector database
on first application startup (RagIngestionService).
Already-ingested files are skipped on subsequent startups.
